# 24 Creative Studio

E-commerce editorial estático com Supabase, painel administrativo, stock por variante e checkout via WhatsApp.

Consulte [LEIA-ME-PRIMEIRO.md](LEIA-ME-PRIMEIRO.md) para instalar, configurar e publicar.

## Stack

- HTML semântico
- CSS responsivo
- JavaScript sem framework
- Supabase Database, Auth e Storage
- Vercel

## Rotas

- `/` — Home
- `/shop` — Catálogo
- `/product/:slug` — Produto
- `/lookbook` — Lookbook
- `/about` — About
- `/admin/login` — Login administrativo
- `/admin` — Painel

No separador **Website** do painel, o proprietário também pode carregar o logótipo oficial e a imagem principal da página inicial.
